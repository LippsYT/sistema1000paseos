# **App Name**: 1000 Paseos

## Core Features:

- Gestión de Agencias: Crear, modificar y eliminar agencias, asignando el estado 'Voucher' o 'Prepago'. Esto implica editar detalles como la información de contacto y la disponibilidad del servicio.
- Control de Acceso de Usuarios: Crear y gestionar cuentas de usuario para las agencias, incluyendo el establecimiento y restablecimiento de contraseñas.
- Panel de Reservas: Ver, modificar o eliminar cualquier reserva realizada por cualquier agencia, ofreciendo un control completo sobre las reservas. También puede ver la capacidad diaria disponible.
- Precios Personalizados: Establecer precios específicos y personalizados para agencias individuales que anulan los precios generales del servicio.
- Cierre de Cuenta: Generar informes de pago para las agencias 'Voucher' dentro de los rangos de fechas especificados, y generar cuentas generales para todas las agencias, calculando automáticamente los totales después de contabilizar varios ajustes. Generar informes en formato PDF.
- Razonamiento de Disponibilidad: Razonar si se debe informar al agente sobre la capacidad sobrepasada o permitir la reserva, incluso si técnicamente está sobre reservada. El LLM debería utilizar una tool para ver las reservas actuales frente a la capacidad.

## Style Guidelines:

- Color primario: Negro (#000000) para una sensación moderna y elegante.
- Color de fondo: Morado oscuro (#301934) para un fondo distintivo.
- Color de acento: Morado brillante (#A020F0) para elementos interactivos y acciones importantes.
- Color secundario: Blanco (#FFFFFF) para elementos de texto y contornos.
- Fuente del encabezado: 'Space Grotesk' sans-serif para una apariencia moderna. Fuente del cuerpo: 'Inter' sans-serif.
- Iconos simples y geométricos para representar varias acciones y categorías, con un enfoque en la claridad y la facilidad de comprensión.
- Diseño limpio y estructurado con una jerarquía clara y una navegación intuitiva.
- Transiciones sutiles y animaciones de carga para mejorar la experiencia del usuario.
